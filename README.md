# 🍅 自律番茄钟

一个 Windows 桌面端的**自控类**番茄钟：不只计时，还让分心成本可见。
Python + PySide6 构建，数据全部存本地 SQLite，无需登录，离线可用。

## 下载即用

到 [Releases](https://github.com/wxz12345/self_clock/releases) 下载 `SelfClock_vX.X.X_win64.zip`，
解压后双击 `SelfClock.exe` 即可（免安装、免 Python 环境）。

从源码运行：

```bash
conda create -y -n self_clock python=3.11
conda run -n self_clock pip install -r requirements.txt
python main.py          # 或双击 启动番茄钟.bat（pythonw，无控制台）
```

## 功能一览

| 模块 | 说明 |
|------|------|
| 🍅 番茄钟 | 专注/短休/长休（默认 45/5/15 分钟，每 4 轮长休），可自定义；进度环 + 剩余时间；时间戳计时（实测 20 秒误差 4ms） |
| 🏷️ 计时归类 | 每次专注选择分类（科研/课程/琐事/娱乐/休息，**可自定义列表**），统计页看时间去向 |
| 📋 任务 | 预估番茄数、设为"当前任务"，完成的番茄自动记账 |
| 🧘 温和自控 | 随时可暂停；但**放弃必须选分心原因**，靠报表让自己"不好意思" |
| 🛡️ 黑名单 | 进程名关键词；专注期间检测**前台窗口**，命中提醒 + 记录（只提醒，不关程序） |
| 🔥 目标与连击 | 每日目标番茄数，连续达标 streak 🔥，达标庆祝通知 |
| 🌳 游戏化 | 完成 1 番茄 +10 金币；树随金币从种子长成大树；专注时随进度生长摇摆 |
| 🎧 白噪音混音器 | 雨声/雷雨/海浪/篝火/风声/鸟鸣/咖啡馆/棕噪音 **8 种真实录音**，多轨叠加、各自音量，专注开始自动接续 |
| 🎯 迷你窗 | 可拖动置顶小窗，**迷你模式接管**：开始/暂停/放弃/跳过全在迷你窗操作，双击返回主窗口 |
| ⏰ 提醒事项 | 事项/时间/地点/备注 + 提前量；到点弹窗+通知，支持"稍后 5 分钟"，错过自动补发 |
| 🪑 久坐提醒 | 规律性休息提醒（间隔/内容可自定义），专注再久也别忘了站起来喝水 |
| 📊 统计 | 概览（30 天柱状图、分心原因、应用使用 Top8、**分类分布**）+ 周趋势（8 周柱状图、**时段热力图**）+ **周回顾**报告页 |
| 🌗 深浅主题 | 设置一键切换深色/浅色，所有自绘控件同步换肤 |
| 💾 数据安全 | 每日自动备份（保留 14 份）+ 手动备份/恢复/CSV 导出 + 按类清空数据 |
| 🔔 托盘常驻 | 点 ✕ 可选"最小化到托盘/退出"并记住选择；tooltip 实时倒计时；**单实例保护**（重复启动唤起已有窗口） |
| 🚀 开机自启 | 设置页开关（注册表 Run 项，默认关闭） |

## 设计说明

- **温和记录型自控**：软件很难真正"强制"人。给放弃加一点"认账"成本（必须选原因），
  再让数据可见（完成率、分心排行、周回顾），让规律自己浮出水面。
- **前台窗口检测**：只有黑名单程序处于前台才算分心；应用使用统计同理（只记程序名与时长，不记窗口标题）。每 5 秒采样一次、按真实墙钟时间累计，并每 60 秒增量落库；会话进行中切到统计页就能看到本次记录，异常退出也不丢数据。
- **核心与界面解耦**：core 不依赖 UI；计时基于时间戳差值，休眠唤醒不漂移。

更多候选功能见 `docs/参考功能汇总.md`。
